# Nurse Connect

**Professional Home Healthcare Website**

## About the Project

Nurse Connect is a home healthcare website designed to present healthcare services and make it easier for visitors to contact the service provider for appointments.

## Features

- Responsive website layout
- Navigation menu
- Healthcare services section
- About section
- Why Choose Us section
- WhatsApp appointment booking
- Direct phone contact

## Services Presented

- IV Hydration Therapy
- IV & IM Medication Administration
- Wound Dressing & Post-Surgical Care

## Technologies Used

- HTML5
- CSS3
